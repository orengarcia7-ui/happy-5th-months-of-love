FIVE MONTHS WITH YOU — DELUXE WEBSITE

Included:
- Envelope opening screen and animated letter card
- Your uploaded photo together
- Uploaded MP3 song
- Song playback begins at exactly 00:50 when the "Keep this moment going" button is tapped
- Lyrics overlay on the photo
- Responsive design for mobile and desktop

IMPORTANT:
The lyric timestamps are initial estimates and may need fine-tuning against the exact recording.
To edit the letter, open index.html and edit the paragraphs inside .letter-content.
To adjust lyric timing, open script.js and edit the timestamps in the lyrics array.
Keep the assets folder beside index.html, style.css, and script.js.

Preview:
Open index.html in a modern browser. For best results, use VS Code Live Server.
